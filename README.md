# QuantDesk

QuantDesk is a multi-market AI paper-trading workbench concept. The first phase is simulation-only: market data may be real, while orders, fills, positions, and PnL remain virtual.

## Project files

- `quantDesk.md` — product scope, simulation boundaries, AI strategy workflow, risk controls, and phased delivery plan.
- `quantDesk-prototype.html` — standalone interactive UI prototype with local demo data.

## Preview

Open `quantDesk-prototype.html` directly in a modern browser. It has no build step or external service dependency. All displayed market and trading data is sample data; the prototype does not connect to a model, market-data provider, or brokerage.
